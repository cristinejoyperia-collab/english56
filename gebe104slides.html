Competencies & Learning Objectives

🎯

3 Target Competencies

  1. (1) Illustrate ratio and proportion using tables and/or the double number line model;
  2. (2) Find how many times one value is larger than another given their ratio, and vice versa;
  3. (3) Solve problems involving ratio and proportion.
📚

Derived Learning Objectives

  • Define ratio, proportion, and equivalent ratios;
  • Read and interpret ratio tables and double number lines;
  • Express ratios in simplest form;
  • Find missing values in proportions;
  • Classify direct, inverse, and partitive proportion; and
  • Solve multi-step real-life ratio problems.

4 Computation Steps & Worked Example [17, 18]

  1. (1) Percentage Score (PS): PS = raw score ÷ highest possible score × 100
  2. (2) Weighted Score (WS): WS = PS × weight
  3. (3) Initial Grade: Sum of the three WS values
  4. (4) Transmutation: DO 8 Table (Appendix B) maps 60.00 to the passing grade of 75.
Worked Example Using Class Data [18]:
If a learner's QA percentage score were 51 (your class MPS), the transmuted grade calculation is:
60 + (0.4 × 51) = 80.4 → rounds to 80.

Ethical Issues in Assessment & Reporting

🔒

Confidentiality

Share scores only with the learner and guardians. Anonymize all class data shared outside (Learner 01–30).

⚖️

Fairness

Use the TOS and validation form so every test item aligns strictly with a taught competency.

🤝

Inclusivity

Treat scores as temporary skill gaps, never permanent ability tracks; strictly avoid harsh words like "bobo."

🏷️

Avoiding Labeling

Say "least-mastered competencies," never "slow learners." The LOP measures item mastery, not children.
